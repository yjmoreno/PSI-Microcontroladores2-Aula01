# Prompt usado na atividade Acelerômetro – Serial

Usei o Claude (Anthropic) como apoio nesta atividade. O pedido foi o enunciado da atividade:

Modifique o projeto fornecido para que utilize threads (1 para aquisição do sinal do acelerômetro e 1 para o envio da aceleração pela serial). Calcule a velocidade e posição (em outro thread) a partir da aceleração usando alguma forma de integração numérica (regra dos trapézios, Simpson e quadratura gaussiana). Crie um branch e envie (push) o seu projeto. Modifique o python para capturar a velocidade e a posição. Envie um gráfico da aceleração, velocidade e posição pelo moodle junto com comentários sobre a estratégia utilizada para as threads em termos de escalonamento.
